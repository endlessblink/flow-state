## 2024-06-23 - Focus Management in Custom Dropdowns
**Learning:** When programmatically managing focus within custom Vue components using `querySelector` (e.g., on a wrapper ref), avoid using generic HTML tags like `'button'`. Always use specific class selectors (e.g., `'.dropdown-trigger'`) to prevent inadvertently focusing the wrong element if multiple matching elements exist within the component tree, or if the trigger element is eventually changed to another type of component. Also, when using ARIA activedescendant on a combobox trigger, the trigger element itself must retain focus; keyboard events from teleported listboxes must be hoisted back to the trigger.
**Action:** Consistently use specific class names or data-testid attributes for focus selectors inside Vue template refs to ensure targeted accessibility behaviors.
