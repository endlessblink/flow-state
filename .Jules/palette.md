## 2025-02-14 - Add ARIA combobox attributes to BaseDropdown\n**Learning:** Custom dropdown components like `BaseDropdown.vue` need the `role='combobox'` on the trigger button, `aria-haspopup='listbox'`, `:aria-expanded`, and `:aria-controls` for screen reader support, as well as unique IDs linking the options to the trigger for `aria-activedescendant`.\n**Action:** When creating or modifying dropdown components, ensure combobox accessibility attributes and dynamically generated IDs (using `useId()` in Vue 3) are present to properly support screen reader accessibility and keyboard navigation visibility.
