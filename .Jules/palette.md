## 2026-04-08 - Keyboard Accessibility of Icon-Only Buttons\n**Learning:** The `tabindex="-1"` attribute was inappropriately used on icon-only `<button>` elements (like show/hide password and quick task triggers) preventing natural keyboard navigation. Additionally, removing the negative tabindex requires explicitly adding `:focus-visible` outline rules for them to be discoverable.\n**Action:** Always verify that interactive custom `<button>` tags do not explicitly disable standard tab-flow, and explicitly include `focus-visible` states mapping to system tokens (like `var(--brand-primary)`) for semantic buttons.
