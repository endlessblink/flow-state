## 2024-04-20 - Missing ARIA Labels on Icon-only and Toggle Buttons
**Learning:** Icon-only action buttons (e.g., close buttons or canvas reveal buttons) frequently lack `aria-label` attributes across layout components, relying instead on `title` which is not reliably exposed to screen readers. Additionally, toggle buttons and filter pills often lack `aria-expanded` or `aria-pressed` attributes to properly communicate their active state to assistive technologies.
**Action:** Always ensure custom icon-only `<button>` elements have an explicit `aria-label` attribute (preferably utilizing the app's existing i18n translation keys like `$t('common.close')` where appropriate), and apply `:aria-pressed` or `:aria-expanded` bound to their respective boolean state variables for toggle interactions. When grouping filter toggles, use `role="group"` with an `aria-label` on the parent container.
